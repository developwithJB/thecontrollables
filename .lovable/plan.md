

# Daily Alignment Premium Feature Plan

## Overview

Upgrade the existing daily email nudge into a two-tier system: free users get the current basic nudge, premium (paid) users get a personalized, scripture-based "Daily Alignment" email generated by AI each morning.

---

## Architecture

### What changes and what stays the same

The current `send-daily-nudge` edge function already handles timezone-aware scheduling, atomic deduplication, and batch processing. We will extend it (not replace it) to:

1. Check if each user is a paid subscriber
2. Route paid users through an AI generation path that produces the Daily Alignment email
3. Keep the existing basic nudge for free users (with a small upgrade CTA appended)

### No new subscription tier needed

The app already has `isPaid: true/false`. All paid users (monthly, yearly, lifetime) get Daily Alignment. No need for a separate "premium" tier field.

---

## Changes

### 1. Create `daily_scriptures` database table

New table with fields:
- `id` (uuid, primary key)
- `verse_reference` (text, e.g. "Proverbs 16:9")
- `verse_text` (text, the full verse)
- `theme_tag` (text, e.g. "awareness", "discipline", "gratitude")
- `rotation_order` (integer, for fallback sequential rotation)
- `created_at` (timestamptz)

RLS: Public SELECT (read-only), no INSERT/UPDATE/DELETE for users. Seed with ~30-50 scriptures tagged by theme.

### 2. Create `daily_alignment_logs` database table

Track which scripture was sent to which user on which day (for rotation and analytics):
- `id` (uuid, primary key)
- `user_id` (uuid)
- `scripture_id` (uuid, references daily_scriptures)
- `nudge_date` (date)
- `generated_content` (jsonb -- stores the AI-generated reflection, question, action, evening prompt)
- `created_at` (timestamptz)

RLS: Users can SELECT their own rows. No direct INSERT/UPDATE/DELETE (edge function uses service role).

### 3. Update `send-daily-nudge` edge function

Major changes to `supabase/functions/send-daily-nudge/index.ts`:

**a) Add entitlement check per user:**
Before generating email content, query `user_entitlements` to determine if the user is paid. The function already uses service role, so it has access.

**b) Add scripture selection logic:**
- Query `user_build_current` for the user's lowest controllable score
- Map controllable to theme tags (awareness, perspective, habit, wellness, environment)
- Also check active `main_quests` title for keyword matching
- Select a scripture matching the theme that hasn't been sent to this user recently (check `daily_alignment_logs`)
- Fallback: rotate by `rotation_order`, wrapping around

**c) Add AI generation for paid users:**
- Gather user context: display name, lowest controllable, current mission, streak count, recent journal/reflection (from `daily_resets` last entry)
- Call `ai.gateway.lovable.dev` with `google/gemini-2.5-flash` using `LOVABLE_API_KEY`
- Prompt: generate context reflection (1-2 sentences), reflection question, micro action, evening check question -- all under 250 words total
- Parse the structured response

**d) Add premium email template:**
New `generateDailyAlignmentContent()` function producing the HTML email with:
- Subject: "{{FirstName}}, stay aligned today."
- Scripture section with verse reference and text
- AI-generated reflection, question, micro action, evening prompt
- CTA: "Open My Dashboard" button
- Clean, minimal styling matching existing email design

**e) Add basic free user email with upgrade CTA:**
New `generateFreeNudgeContent()` function (simplified version of current daily email) that appends an "Unlock Daily Alignment" upgrade CTA linking to `/billing`.

**f) Log alignment data:**
After sending a premium email, insert into `daily_alignment_logs` for rotation tracking and future analytics.

### 4. Update Profile Settings Modal

In `src/components/ProfileSettingsModal.tsx`:

- Rename the "Email Nudges (Optional)" section
- For paid users: show "Daily Alignment" as the daily option label with description "Personalized scripture, reflection, and one clear action each morning"
- For free users: show the existing locked state but update copy to mention Daily Alignment

### 5. Add Premium Feature Card to Dashboard

Create a small promotional card component that appears for free users (e.g., in the dashboard sidebar or below Today's Actions):

```
Daily Alignment
Personalized scripture. Real-time growth reflection. One clear action per day.
Built from your actual life.

[Upgrade to Premium]
```

This will be a new component `src/components/dashboard/DailyAlignmentPromo.tsx` shown only to free users who have nudges disabled.

### 6. Seed Scripture Data

Insert ~40 scriptures covering all 5 controllables plus additional themes (trust, resilience, gratitude, discipline, patience). Each tagged with a primary `theme_tag` and assigned a `rotation_order`.

## Dependencies

- No new npm packages
- Uses existing `LOVABLE_API_KEY` for AI generation (same as AI chat)
- Uses existing `RESEND_API_KEY` for email sending
- No new secrets required

## Constraints followed

- Email under 250 words
- No long dashes
- No generic cliches
- Only emoji allowed: a single book icon for the scripture section
- Tone: grounded, wise, clear
- All AI generation uses the Lovable AI gateway (no external API keys)

## Priority order

1. Database tables (scriptures + alignment logs)
2. Seed scripture data
3. Update send-daily-nudge with entitlement check + AI generation + premium template
4. Update settings modal labels
5. Add dashboard promo card
