# Christian Formation Editorial Launch Checklist

No representative seed is approved merely because it exists in the repository. A named human must complete this checklist in the admin workflow.

## Item review

- [ ] Stable ID/slug, content type, track, day range, season, chapter, and spoiler level are correct.
- [ ] Scripture reference parses and the translation is named/licensed for the intended use.
- [ ] Scripture quotation and interpretation are distinguished.
- [ ] Theology, tradition, historical claim, interpretation, and creative reconstruction are visibly classified.
- [ ] Every historical claim has a source citation and review date.
- [ ] Creative reconstruction is explicitly labeled in the user preview.
- [ ] Book alignment is accurate and avoids unintended spoilers.
- [ ] Movement guidance accepts legitimate adaptation and defers to clinical/local safety guidance.
- [ ] Service content does not invite recipient identity, image, hardship, or contact details.
- [ ] Recovery language is honest and grace-centered, never shame-driven.
- [ ] Completion language does not imply earned salvation, approval, maturity, superiority, or guaranteed transformation.
- [ ] Email guidance contains no prayer/reflection/proof/health/covenant/service-recipient/Witness-note content.
- [ ] AI-assisted text has been materially reviewed by a human.

## Workflow approval

- [ ] Author submits a new immutable version.
- [ ] Independent reviewer is not the author.
- [ ] Theological review is approved by a named accountable person.
- [ ] Historical review is approved where applicable.
- [ ] Pastoral, privacy, safety, and accessibility copy review is complete.
- [ ] Preview is checked at desktop and mobile widths.
- [ ] Effective date and last-reviewed date are intentional.
- [ ] Publication status is changed only after all gates pass.
- [ ] Export is archived for rollback/audit before bulk import or publication.
